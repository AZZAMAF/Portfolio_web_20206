# Azzam Firdaus — Portfolio Website

A pixel-perfect, responsive personal portfolio website crafted directly from the design in `Portfolio.png`.

## ✨ Features
- **Floating Pill Navbar**: Sleek burgundy (`#76222a`) rounded navigation bar with responsive mobile menu toggle.
- **Hero Section**:
  - Quote testimonial box: *"Jenny’s Exceptional product design ensure our website’s success. Highly Recommended"*.
  - Call to action button: `Let's Talk`.
  - Azzam's cutout portrait with soft warm glow backdrop and sparkling star.
  - Serif typography with experience counter badge (`3 Years Experince`).
- **Infinite Slanted Ribbon / Marquee**:
  - Slanted dark burgundy marquee with smooth infinite scrolling: `WEB DEV ✦ WEB DESIGN ✦ DEPLOYMENT`.
- **About Section**:
  - Bold typography with matching burgundy description.
  - 3 Interactive service cards: `Design 01`, `Frontend 02` (highlighted maroon card), and `Coaching 03` with "See more" modals.
- **Career Path / Experience Section**:
  - Teaching group photo at Al Hazen Academy.
  - Interactive slider timeline dots with details and dates.
- **Portfolio Showcase**:
  - Silver 3D metallic stars and sparkling red star accents.
  - Interactive category filter tabs: `All`, `Web Design`, `Landing Page`, `Poster`, `Website`.
  - 8 Project cards grid with mobile app mockup, hover zoom, and top-right arrow action buttons opening modal previews.
- **Discussion / CTA Section**:
  - Vintage red radio accent and silver star decoration.
  - Working email contact form with toast confirmation.
  - Trust indicators: 4.9/5 Average Ratings, 25+ Winning Awards, Certified Product Designer.
- **Footer Section**:
  - Curved top burgundy container with `Lets Connect there` banner and `Hire me ↗` action.
  - JCREA brand bio, social media links (Facebook, WhatsApp, Instagram, X/Twitter).
  - Navigation links, direct contact details, and working newsletter subscription box.

## 🚀 How to Run / View

### Option 1: Open directly in browser
Double click or open `index.html` in any web browser:
```bash
# Example on Linux:
xdg-open /home/zamxy/Portfolio-web/index.html
```

### Option 2: Run with local HTTP server
```bash
cd /home/zamxy/Portfolio-web
python3 -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
